기존 데이터 분석의 3대 장벽

수작업과 IT 의존도가 비즈니스 속도를 늦춥니다

block

어렵다 (High Barrier)

소수 전문가의 전유물

SQL 등 전문 기술 지식 필수. 지나치게 긴 학습 시간으로 인해 현업 적용 실패.

schedule

느리다 (Time Consuming)

비즈니스 속도 저하

단 하나의 리포트를 위해 데이터 추출, 개발, 검증의 복잡한 대기 시간 발생.

lock

활용성 낮음 (Low Utility)

단순 조회용 도구로 전락

1회성 정형 리포트로 끝나며, 비정형 데이터 분석이나 생성된 지식의 재활용 불가.
